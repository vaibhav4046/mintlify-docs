## When to use it

Retrieve all connectors configured for your organization to see their status and configuration.

## Endpoint

`GET /v2/connectors`

- **Auth:** Bearer token (session or API key)

## Example

<CodeGroup>
```bash cURL
curl 'https://api.hydradb.com/v2/connectors' \
  -H "Authorization: Bearer $HYDRADB_API_KEY"
```
</CodeGroup>
